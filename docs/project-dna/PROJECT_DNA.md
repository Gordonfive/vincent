# Project DNA

Canonical product name: **VINCENT — Verified Intelligent Networked Codex Execution Node Technology**. Early internal protocol, package, service, and filesystem identifiers may remain during a deliberate compatibility migration, but user-facing product language must use Vincent.

## Mission

Build an open-source, Linux-first platform that turns ordinary computers into reproducible, disposable Codex development workers. The owner should eventually direct software development through ChatGPT from a phone while Git preserves work, reports, decisions, and project intent.

## Why

Human attention should be spent on product judgment, priorities, risk, and acceptance—not repeatedly rebuilding environments, opening terminals, synchronizing repositories, restarting agents, or copying reports.

## Non-negotiable principles

- Git is the durable technical authority.
- Repository documents are durable memory; chat history is temporary.
- Workers, coordinators, workstations, Codex sessions, and ChatGPT threads are replaceable.
- Project DNA preserves why a project exists and how decisions are made.
- Development autonomy does not imply production autonomy.
- Human judgment and owner authority remain permanent.
- Reproducibility is proven by destruction and recovery, not by a single working machine.
- Prefer simple, established components and introduce complexity only for a demonstrated requirement.
- Core infrastructure is generic; owner, fleet, and project configuration are separate.

## Authority

- **Owner:** final product, priority, security, production, major architecture, and Project DNA authority.
- **ChatGPT:** planning, decomposition, worker selection, report review, and integration recommendations; consequential decisions must become durable.
- **Coordinator:** dispatch and operational synchronization; it does not invent product priorities.
- **Codex workers:** bounded implementation and ordinary engineering decisions within task authority.
- **Git:** durable technical state and provenance.

## Success

The owner can erase a compatible spare computer, provision it from a reproducible Debian installer, enroll a unique identity, assign work remotely, and receive pushed, validated results without sitting at the machine. Mature Mission Control restores an entire multi-project development operation after loss of workers, coordinator, and chat history.

## Deliberate non-goals for the initial system

Kubernetes, a custom distributed database, local LLM infrastructure, autonomous production deployment, massive fleets, a complex dashboard, and support for every OS or source-control provider.

Changes to mission, authority, product philosophy, or production boundaries require owner approval.
