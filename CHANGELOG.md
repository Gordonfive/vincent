# Changelog

This file records release-level changes to Vincent. It is intentionally concise and is updated at release boundaries rather than for every pull request.

Vincent uses Semantic Versioning. Pre-1.0 releases use `0.x.y`; the first release satisfying the accepted Vincent 1.0 requirements and acceptance criteria becomes `1.0.0`.

Installer build numbers are separate immutable provenance identifiers and are not Vincent software versions.

## Unreleased

Current pre-1.0 development includes the Debian installer/runtime foundation, standalone READY model, networking/diagnostics, trusted update lifecycle, AI-provider adapter foundation, and documentation/governance reset described in `docs/STATUS.md` and the active pull requests/issues.

Detailed implementation history remains in Git and pull requests. Full release notes and downloadable artifacts will be published through GitHub Releases.
